# Depi-Grad-Project-Data-Analysis-Supply-Chain

## 1. Project Name

Supply Chain Analysis

## 2. Project Idea

This project analyzes a supply chain dataset for skincare company using Power BI. It covers cleaning and modeling the data, defining business questions that matter to decision makers, building DAX measures (KPIs), and presenting the findings in an interactive dashboard.
